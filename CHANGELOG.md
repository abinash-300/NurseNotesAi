# NurseNote AI — v1.0.0

First public release.

## Features
- Voice recording with Web Speech API
- AI-powered SOAP note generation via Groq
- 6 clinical specialty templates
- Note length control (Brief/Standard/Detailed)
- Session history (last 5 notes)
- Auto-clear privacy timer
- Onboarding flow
- Clinical disclaimer
- Copy and share notes
- Mobile responsive

## Requirements
- Chrome or Edge browser for voice recording
- Free Groq API key from console.groq.com

## How to run locally
npm install
npm run dev
